One-time setup on github.com:
1. Create a private repo named gitnotes-sync — no README needed
2. Create a token and include that repo in its Repository access, with Contents: Read and write
3. Paste the token here, then pull down on your notes to sync — same account on every device, and it takes over from there.
Notes merge into a single onenotes.json file on any WebDAV server — Nextcloud, Koofr, TeraCloud or your own.
